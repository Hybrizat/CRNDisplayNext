# CRN Display Native Extended

[English](https://github.com/Hybrizat/CRNDisplayNext/blob/Neoforge-1.21.1/README_en.md) | 中文

Create: Railways Navigator Display Native Extended 是 [Create: Railways Navigator](https://github.com/MisterJulsen/Create-Train-Navigator) 的附属模组，提供 JR 东日本风格的站台电显、列车方向幕与车内 VIS。

---

## 显示类型

| 显示器 | 注册名 | 安装位置 | 内容 |
| --- | --- | --- | --- |
| JRE 站厅显示 | `jre_station` | 车站 | 出发板，含「番線」列 |
| JRE 站台显示 | `jre_platform` | 站台 | 出发板，不含番線列，可选方向箭头 |
| JRE 前面幕 | `jre_front` | 车头 | 列车类别色块 + 行先／线路名 |
| JRE 侧面幕 | `jre_side` | 车身侧面 | 次站／行先／线路名三种布局 |
| JRE 乘客 VIS | `jre_vis` | 车内 | 路线图（上部信息 + 下部站名条带） |
| 自定义图片显示 | `jre_graphics` | 任意 | 显示一张网络图片 |

---

## 主要特性

### 直通区段

- 行先跨区段解析到**整个直通组的终点**，而不是停在区段交接站
- 站台／站厅电显同样正确：CRN 只把行程快照交给车上的显示器，因此客户端会向服务端询问每趟车的直通终点，按（列车，运行会话）缓存，先显示旧值再后台刷新
- 区段之间线路／类别不同时颜色随之切换，VIS 的路线条带按区段分段配色

### 终点站

- 以**本次停靠所属的区段**为准。站台电显上每一行都是一次停靠，不能按列车当前所在区段来标注
- 尊重 CRN 的**车站黑名单**：终点站被拉黑时向前回溯到最近的可见站
- 环形／折返时刻表不会把首站误判为终点

### 站台电显

- 列车文字可选：列车名称／列车类别／线路名称
- 类别或线路色背景（可关）
- 时间格式、同一列车多次显示、各列宽度（`-1` 为自动，按整块屏幕的最宽文本对齐）
- 可选显示「经由」站
- 站台显示可显示 ←／→ 方向箭头，按行内车次的车站名或站台号匹配你配置的左右过滤器

### 方向幕

- **前面幕**：左侧色块停靠时显示列车类别、行驶时显示线路名；B 栏可选行先或线路名，与左侧内容相同时自动留空
- **侧面幕**：左侧色块恒为线路名，不随停靠状态变化
  - 次站模式（双行）：左侧线路名，右上行先，右下「次は ○○」
  - 行先：线路名 + 行先
  - 线路名：线路名占满整块屏幕

### 乘客 VIS

- 上部：列车类别色块、行先、现在站／下一站、时刻
- 下部：路线条带，按区段分段配色；停靠时指针指向当前站，行驶时显示指向前方站的绿色箭头
- 已通过的车站灰显，且不会投影到下一个周期
- 可开关：线路色、请勿上车文本、换乘信息、车内统计、车厢编号

### 自定义图片显示

- 填入 http(s) 直链即可
- 由服务端下载并缓存，客户端不直接访问网络；可用「浏览…」预览网址，或直接选用服务端已缓存的图片
- 图片随时可改，列车已实体化时同样生效

## 模组依赖

- Create 6.0.10
- Create: Railways Navigator beta 0.10.0 C6
- DragonLib beta 3.0.28

*只在以上模组版本中测试，不保证其他版本的兼容性*

---

## 安装

- 单人游戏：放进 `mods` 即可
- 专用服务器：**服务端也需要安装**。直通区段的行先与自定义图片显示依赖服务端解析／下载，只装客户端时这两项不生效，其余显示正常

---

## 从 0.2.2 升级

0.3.0 起要求 **CRN 0.10.0-C6**。仍在使用 CRN 0.9.x 的用户请留在 0.2.2。

- 不再使用 Mixin，改为只调用 CRN 的公开 API
- 移除「隐藏技术停车」，请改用 CRN 原生的通过站／技术停车设置
- 终点站改为「当前区段的终点」，并开始尊重车站黑名单
- 侧面幕左侧色块由列车类别改为线路名称

## 已知问题

- 站前折返时如果两段时刻表分区的列车类别不同，可能出现发车后短时间列车类别识别错误
- 当显示器宽度不足时可能会出现问题
