# CRN Display Native Extended
English Readme is [HERE](https://github.com/Hybrizat/CRNDisplayNext/blob/Neoforge-1.21.1/README_en.md)

Create: Railways Navigator Display Native Extended 是 Create: Railways Navigator 的附属模组

## 功能目标

- **隐藏技术停车**：对于站前折返时刻表（A-B-C-||-C-B-A），隐藏停站时长为0的站点，使显示内容正确（C→B而非C→C）
- **新显示格式**：JR 东日本风格的站台电显、（计划实现中）VIS与行先表示

---

## 未来计划
- CR、JRW等风格显示
- 线路显示器

## 模组依赖
- Create 6.0.9
- Create: Railways Navigator alpha 0.9.0 C6+2
- DragonLib beta 3.0.24

*只在以上模组版本中测试，不保证其他版本的兼容性*
